# Nithin Gampa — Analytics portfolio (easy GitHub upload)

This folder contains **only files**, no subfolders, so all items can be selected at once in GitHub's **Add file > Upload files** picker.

## Publish
1. Open https://github.com/gnithin080/gnithin080.github.io .
2. Click **Add file → Upload files**. Open the extracted `Nithin_Gampa_Easy_GitHub_Upload` folder and select **all 13 files inside** (not the containing folder, and not the ZIP).
3. Commit with message `Add analytics portfolio`. Verify `index.html` is visible at the top of repository.
4. Open **Settings → Pages**, use **Deploy from a branch** → `main` → `/ (root)`, then Save.
5. After deployment, visit https://gnithin080.github.io and test dashboard and resume links.

This public website demonstrates synthetic records only. The native Power BI PBIX has not been created; Power BI source/reference files are included to support recreation.
